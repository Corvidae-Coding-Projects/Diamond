## Inputs and independent expectations

owners, 3 nominal scope IDs, 7 sampled scope sets and
all 7 nonempty read/count/join operation sets. Concrete

Six valid codec fixtures cover signed 64-bit bounds and values beyond JavaScript

integers, overflow, missing/unknown fields, surrogate code points, wrong nominal
tags, invalid Options/enums and mismatched wrapper tags. Raw HTTP additionally
checks strict envelopes/duplicates, methods, versions, origin/forwarded authority,
forged credentials, undeclared routes and separation of cookie/RPC and bearer API.

Expected resource visibility comes from fixed synthetic membership/row fixtures
and a separate policy/credential intersection model; the driver does not import
production policy/SQL code or adopt responses as its expected answer. Persistent
mutations and rejected credential issuance have independent committed-row
observations. Known/unknown acceptance responses are compared directly; no
constant-time timing claim is made.

## Shared rates, faults and pressure

Database-clock one-minute caps are auth global 120 / peer 100 / declared subject 12 and
API global 600 / peer 300 / token or public subject 120. Authentication subjects are
specified username/email fields; bodyless account operations use global/peer
limits plus issuance bounds. Multiple actual credentials and loopback source
addresses isolate narrower subjects from the peer/global gates. Each functional
phase deliberately expires its owned rate rows before starting; no such fixture
intervention occurs during a rate survival/cap/restart phase. The rate component
made 1,584 actual requests with at most 8 clients.

The transparent PostgreSQL fixture forwards real protocol bytes. It withholds
an actual COMMIT acknowledgment and pauses actual completed queries; it never
fabricates database responses. Deferred SQLSTATE 40001 faults are generated by
real isolated PostgreSQL triggers. Delivery faults change only the owned private
mailbox path. Pending challenges/counters/record state are independently read
back. Earlier serializable snapshots are permitted to finish in their declared
serial order or distinctly abort; new requests after committed revocation deny.

## Replay and boundaries

```sh
cargo build --locked
python3 verification/web_five_independent.py
```

The runner pins the executable/library, checks artifact fingerprints in every
component and runs actual CLI, Unix-socket PostgreSQL, private development
delivery, direct two-node HTTP and an external public-API Rust consumer. It
implements no application handlers or fake authentication/delivery responses.
All accounts are synthetic and email addresses end in `.invalid`.

Browser account controls and identity-transition/cache behavior were operated
separately by the root agent; this backend receipt does not claim browser UX
validation. It does not cover public TLS/proxy deployment, SMTP/external delivery,
file/object storage, outbound integrations, jobs, old/new upgrade coexistence,
host/database-owner compromise or all possible corrupt states. It does not
exhaust account/session/keyspace/64-active-credential ceilings, statistically
qualify timing, run 100 clients for 30 minutes, establish production capacity or
prove exhaustive security. W4/W3 preservation campaigns are separate evidence.
